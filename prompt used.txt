You are a senior JavaScript/TypeScript game developer, game designer, and Cloudflare full-stack architect.

Build a complete browser-based fantasy Tower Defense game inspired by the classic feel, pacing, strategy, progression, and atmosphere of Warcraft III custom Tower Defense maps.

The game must be completely original.

DO NOT copy or reuse Warcraft, Blizzard, Warcraft III, World of Warcraft, or other copyrighted:
- characters
- unit names
- tower names
- maps
- artwork
- icons
- models
- music
- sounds
- UI assets
- lore
- trademarks

Create an original fantasy universe with its own names, artwork, enemies, towers, effects, UI, and game identity.

# 2. Game Concept

Create a fantasy Tower Defense game where waves of creatures travel through a fixed path toward the player's stronghold.

The player earns gold by defeating enemies and spends that gold to build and upgrade defensive towers.

The objective is to survive as many waves as possible while achieving the highest score.

The game should capture the satisfying progression of classic Warcraft III custom Tower Defense games:

- increasingly difficult waves
- tower upgrades
- different enemy types
- different tower roles
- strategic tower placement
- gold/resource management
- occasional powerful random bonuses
- increasingly hectic late-game waves
- high-score chasing

The initial version should be a polished single-map game that can later support additional maps.

# 3. Main Game Flow

Main Menu

→ Select Difficulty

→ Enter Player Name

→ Start Game

→ Build Towers

→ Start / survive enemy waves

→ Earn Gold

→ Upgrade or build more towers

→ Occasionally receive Power-Ups

→ Continue until player lives reach zero

→ Calculate final score

→ Save score

→ Display results and leaderboard

→ Play Again

# 4. Difficulty Modes

Provide three difficulty modes:

## Easy

Designed for new or casual players.

Example balancing:

- Starting Gold: 700
- Starting Lives: 25
- Enemy HP multiplier: 0.80
- Enemy speed multiplier: 0.90
- Gold reward multiplier: 1.15
- Difficulty score multiplier: 1.0x

## Medium

Normal intended experience.

- Starting Gold: 600
- Starting Lives: 20
- Enemy HP multiplier: 1.00
- Enemy speed multiplier: 1.00
- Gold reward multiplier: 1.00
- Difficulty score multiplier: 1.5x

## Hard

For experienced Tower Defense players.

- Starting Gold: 500
- Starting Lives: 15
- Enemy HP multiplier: 1.30
- Enemy speed multiplier: 1.10
- Gold reward multiplier: 0.90
- Difficulty score multiplier: 2.0x

Keep these values centralized in configuration rather than hardcoding them throughout the game.

Difficulty must affect both gameplay and final scoring.

# 5. Wave System

Create an endless or long-running wave system.

Each wave becomes progressively harder.

Enemy scaling should consider:

- wave number
- difficulty
- enemy HP
- movement speed
- armor/resistance
- number of enemies
- enemy variety

Example:

Wave 1-5:
Basic enemies

Wave 6-10:
Faster enemies introduced

Wave 11-15:
Armored enemies

Wave 16-20:
Magic-resistant enemies

Wave 20:
Boss wave

Continue this progression with stronger combinations.

Every 5 waves should feel like a noticeable increase in difficulty.

Every 10 waves should include a boss or major challenge.

Do not simply increase HP forever. Introduce enemy mechanics that force players to change strategies.

# 6. Enemy Types

Create at least these enemy archetypes:

## Grunt

Basic enemy.

Balanced HP and speed.

## Runner

Low HP but very fast.

## Brute

Slow movement but very high HP.

## Armored Enemy

Reduced physical damage.

## Arcane Enemy

Reduced magical damage.

## Regenerator

Slowly regenerates HP.

## Swarm Enemy

Weak individually but appears in large groups.

## Boss

Extremely powerful enemy appearing periodically.

Bosses can have special abilities such as:

- temporary movement speed increase
- temporary damage resistance
- regeneration
- summoning smaller enemies

Use original fantasy names for the final enemy designs.

# 7. Tower System

Start with at least five tower archetypes.

## Archer Tower

Good against basic enemies.

Area-of-effect damage.

Good against groups.

## Frost Tower

Low/moderate damage.

Slows enemy movement.

## Arcane Tower

High magical damage.

Good against armored enemies.

Example:

Level 1

Store tower balancing data in configuration files.

# 9. Power-Up System

Implement random Power-Ups.

Power-Ups should feel exciting but should not completely remove the strategic nature of Tower Defense.

Power-Ups may be granted:

- after certain waves
- by defeating bosses
- through a low random drop chance from enemies

When a Power-Up becomes available, clearly notify the player.

Suggested Power-Ups:

## Gold Rush

Instantly receive bonus gold.

## Meteor Strike

Player selects an area.

A meteor deals massive AOE damage.

## Time Freeze

Freeze all enemies for several seconds.

## Battle Cry

All towers gain increased attack speed for 10 seconds.

## Arcane Surge

All towers gain increased damage temporarily.

## Emergency Repair

Restore several lost lives.

Do not allow lives to exceed the configured maximum unless explicitly designed as an upgrade.

## Treasure Goblin

Spawn a special bonus enemy.

Killing it before it escapes gives a large gold reward.

## Double Bounty

Enemies provide double gold for a limited duration.

## Tower Overcharge

Randomly select one existing tower and dramatically increase its power temporarily.

## Ancient Blessing

Randomly choose between several smaller positive effects.

Power-Ups should have rarity:

- Common
- Uncommon
- Rare
- Legendary

Example drop probabilities:

Common: 55%
Uncommon: 28%
Rare: 13%
Legendary: 4%

The rarity system and probabilities must be configurable.

Prevent the Power-Up system from becoming pay-to-win or dependent on real money.

# 10. Random Power-Up Presentation

When the player earns a random Power-Up:

1. Pause or slow the game appropriately.
2. Display a small fantasy-style reward animation.
3. Reveal the Power-Up.
4. Explain the effect.
5. Allow the player to activate it immediately or store it if appropriate.

Limit stored Power-Ups to avoid hoarding.

Suggested inventory limit:

3 Power-Ups.

- building towers
- upgrading towers

# 13. Scoring

Create a scoring system that rewards both survival and performance.

Score should consider:

- enemies defeated
- waves completed
- bosses defeated
- remaining lives
- difficulty level
- possibly unused gold at game completion

Example concept:

Enemy Kill Score
+
Wave Completion Bonus
+
Boss Bonus
+
Remaining Lives Bonus
=
Base Score

Base Score × Difficulty Multiplier
=
Final Score

Do not allow easy-mode farming to dominate the global leaderboard.

Difficulty multipliers should reward harder modes.

Keep the scoring algorithm centralized and unit-tested.

# 14. High Score System

Store high scores permanently in Cloudflare D1.

For each completed game record:

- id
- playerName
- difficulty
- highestWave
- finalScore
- enemiesKilled
- bossesKilled
- remainingLives
- gameDuration
- createdAt

Do NOT trust a score supplied directly by the browser.

Implement reasonable server-side validation for submitted scores.

At minimum validate:

- valid difficulty
- realistic wave number
- non-negative values
- valid player name
- maximum player-name length
- realistic score boundaries
- payload structure

Structure the backend so stronger anti-cheat validation can be added later.

- projectiles
- particle effects
- frequently spawned enemies
